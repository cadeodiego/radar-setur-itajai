# RADAR — monitoramento de mídia

Painel de clipping de imprensa sobre turismo e eventos de Itajaí. Atualiza
sozinho todo dia às 10h (horário de Brasília) pelo GitHub Actions.

O painel é publicado por GitHub Pages e traz `noindex` e `robots.txt` — não é
indexado por buscador, mas **é acessível a quem tiver o link**. As miniaturas
são cacheadas com crédito ao veículo e link para a matéria original; qualquer
pedido de remoção é atendido.

Método, limites de cobertura e critério de classificação ficam declarados na
própria página, na seção "Metodologia e limites" — inclusive o que este painel
**não** vê.

Produto da /PLAN. O motor e a documentação técnica vivem no repositório de
trabalho; aqui fica a instância publicada.
